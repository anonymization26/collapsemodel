Target A-opt 的平均真实 top-10 recall 为 `98.333%`，平均组合缩减为 `50.110%`，验证选中组合的
平均测试归一化 Brier 遗憾为 `0.001311%`，故预注册 H3 判定为 `PASS`。但 Second-moment MMD 的

H2/H2b 失败结论。权威产物和逐方法结果见 `e2b_fixed_cost_shortlist/domainnet_v1/README.md`。

### 随机流与完整性审计

几何、目标抽样、源抽样和条件偏移方向使用独立 RNG 流。目标样本量扫描共享同一个真实目标矩、
同一个源候选池和嵌套目标样本；不同预算共享同一目标测试集。合并器自动拒绝重叠种子、配置不一致、
重复行、不完整网格、混合代码版本以及受控变量随目标样本量变化。

- 共享模型审计：33,480 个分组，选择、目标风险和 oracle 风险均为 0 个不一致；
- 条件偏移审计：29,160 个分组，选择、目标 MSE 和 oracle MSE 均为 0 个不一致；
- 当无标签目标样本数为 `16/32/128/512` 时，估计目标矩与真目标矩贪心选择的一致率分别为
  `83.06%/87.50%/94.35%/97.31%`。

### E1：目标条件选择

- H2 通过。最强目标无关基线为 Effective Rank；Target A-opt 的平均相对风险改善为 `4.23%`，
  配对 bootstrap 95% 改善区间为 `[3.86%, 4.62%]`，`98.61%` 的设计配置满足 0.5% 容差下非劣；
- H2b 通过。最强同信息权限基线为二阶特征 MMD；平均相对风险改善为 `14.85%`，
  95% 改善区间为 `[13.99%, 15.70%]`，非劣比例为 `100%`；
- Target A-opt 的平均归一化遗憾为 `0.01400`，top-10 组合召回率为 `91.48%`；
- 条件偏移为 `0.0/0.5/1.0` 时，Target A-opt 的平均归一化遗憾为
  `0.211/2.197/3.143`。偏移达到 `0.5` 后，其优势消失并略劣于 Effective Rank，构成明确的适用边界。

这些门槛只在当前线性高斯生成族上通过，不能替代 E2 的真实冻结表示证据。目标秩变化同时改变生成族
中的源协方差结构，因此按目标秩分层的热图是场景比较，不应解释为目标秩的单因素因果效应。

### E5：低秩摘要与证书

- 所有确定性风险区间对 full-Gram 风险的覆盖率均为 `100%`；
- H5 未通过。打包对称 Gram 作为分母时，低于 `25%` 平均字节预算的最佳策略仅达到
  `15.42%` 选择一致率和 `3.91%` 成对证书率；
- 覆盖完整网格且保证 `100%` 选择一致的最省全量回退策略仍需约 `160.0%` 的打包 Gram 字节。

因此，低秩区间在当前实现中数学上可靠，但没有实际通信压缩价值。不得使用稠密 `d x d` Gram 分母
或只挑选低维子网格来宣称 H5 通过。

### E2：真实冻结表示选择

- PACS、Office-Home、ResNet-50 和 DINOv2 ViT-B/14 四个运行全部完成；
- 覆盖 8 个数据集-目标域统计单位、`K in {1, 3, 5}` 和 Random 的 20 次重复，共 1,536 行原始指标；
- H2 未通过：Target A-opt 相对 DPP Subspace 的平均相对 Brier 改善为 `0.351%`，`delta` 的
  95% 区间为 `[-0.007449, 0.000731]`；
- H2b 未通过：相对 Second-moment MMD 的平均相对改善为 `0.273%`，`delta` 区间为
  `[-0.003392, -0.000712]`，但未达到预注册的 `2%` 实质改善门槛；
- 两项比较在 `0.5%` 容差下的不劣比例均为 `100%`。

真实结果说明当前目标条件二阶几何只有很小的方向性收益，不能支撑相对经典或同信息基线的实质
优势主张。权威结果见 `e2_dataset_selection/method_v1/summary/summary.json`，完整解释见
`e2_dataset_selection/method_v1/README.md`。确认性流程按预注册停止规则不再扩展到 E4 或 E7。
