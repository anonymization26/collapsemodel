# A-opt 与 MMD 的互补性探索审计

日期：2026-09-26。范围：复用冻结排序、验证损失和测试损失，**不重训、不启动服务器实验、不改论文**。

## 结论

**A-opt 确实能补回 MMD 漏掉的好候选，但“补回前十名”大多没有转化为更好的最终选择。**
在50候选、逻辑回归、Brier口径下，48个新增种子重复任务中有26个出现这种补回；
其中只有6个任务的A-opt新增候选包含比MMD最终选择更低的测试损失，验证最终兑现4个改善，
另有1个任务变差。合并名单的平均收益较小，且集中于两个目标域和同一个编码器。

固定50个监督评价时，简单交替合并排序有局部改善信号；“MMD先筛、A-opt再排”没有在该预算下胜过MMD。
在227候选的原主预算下，两种读出器的全部组合规则均未改变最终Brier损失。
这些结果支持继续研究**特定小预算下的互补性**，不支持已经得到普遍更优的新算法。

## 审计定义

对预算s，记A-opt与MMD各自前s名集合为A和M，测试损失前十名为T。

1. A-opt补回MMD遗漏的好候选，指 `(A - M) ∩ T`；反向补回为 `(M - A) ∩ T`。
2. “有用补入”进一步要求A-opt新增候选的测试损失低于MMD经验证选中的候选。
3. “最终改善”要求在并集上重新按验证损失选择后，所选候选的测试损失确实低于MMD原选择。
4. “改善”与“变差”按绝对差超过1e-12计数，仅用于排除数值噪声，不是实质效应门槛或显著性检验。
5. 前十名延续原协议的字典序平局规则；同时给出边界平局按份额分配的敏感性结果。
6. oracle保留采用“至少保留一个具有最低记录测试损失的候选”，不把等损失oracle的身份差异当成遗漏。

高召回不等于最终质量改善。例如，新加入的前十名候选仍可能不如MMD已经选中的候选。
这与“存在更好的补入候选，但验证没有选中”是不同情形，本审计分别计数。

## 比较规则

| 规则 | 短名单构造 | 监督评价数 |
| --- | --- | --- |
| MMD | MMD前s名 | s |
| A-opt | A-opt前s名 | s |
| 并集 | 两个前s名集合去重合并 | r = 并集大小 |
| 匹配数量的MMD | MMD前r名，逐任务匹配并集数量 | r |
| MMD先交替 | 按M1、A1、M2、A2等顺序读取排名，去重直到s个 | s |
| A-opt先交替 | 按A1、M1、A2、M2等顺序读取排名，去重直到s个 | s |
| MMD再A-opt | MMD前min(2s,455)名内，按A-opt原排序取s个 | s |

匹配数量的MMD是事后的评价数量对照；不同任务的r可能不同。
这里的“等预算”只指监督评价的唯一候选数量，并没有测量筛选开销或总时间。
交替合并可能需要计算两种排序，不能据此声称等时间或实际加速。

## 50候选时的补回与最终选择

下表均为四个新增种子，分母为每个读出器48个重复任务，指标为Brier。

| 检查 | Logistic | Ridge |
| --- | ---: | ---: |
| A-opt补回至少一个MMD遗漏的前十名候选 | 26/48 | 24/48 |
| 补回的候选-任务出现次数 | 52 | 54 |
| MMD反向补回至少一个A-opt遗漏的前十名候选 | 30/48 | 30/48 |
| 反向补回的候选-任务出现次数 | 101 | 122 |
| A-opt补入候选中存在测试损失优于MMD最终选择者 | 6/48 | 5/48 |
| 并集改善名单内最佳测试损失 | 5/48 | 4/48 |
| A-opt补回MMD未保留的任一测试oracle | 4/48 | 3/48 |
| 验证在并集中选中了A-opt独有候选 | 5/48 | 5/48 |
| 并集最终选择优于MMD原选择 | 4/48 | 5/48 |
| 并集最终选择劣于MMD原选择 | 1/48 | 0/48 |
| 并集最终选择与MMD原选择测试损失相同 | 43/48 | 43/48 |

Logistic中，26个有前十名补回的任务，有20个并没有补入比MMD最终选择更好的测试候选。
另6个确有这种机会，其中4个实现最终改善，2个没有实现。因此，不能将所有未兑现的前十名补回都解释为验证失败。
收益也不是单向的：此预算下，MMD补回A-opt遗漏的前十名候选更多。

50候选时两种读出器的Brier前十名边界均无平局，按份额分配的补回统计与字典序统计相同。
错误率补充分析保留两种口径，避免将离散损失的平局当成强互补证据。

## 是否只是多评价了候选

Logistic、Brier、新增种子、s=50的结果如下。差值为方法减MMD前50名，负值较好。

| 规则 | 平均评价数 | 平均最终Brier | 相对MMD差值 | 更好/更差/相同任务 |
| --- | ---: | ---: | ---: | ---: |
| MMD | 50 | 0.864365469 | 0 | 0/0/48 |
| A-opt | 50 | 0.864511111 | +0.000145643 | 6/9/33 |
| 并集 | 69.0625 | 0.864109383 | -0.000256086 | 4/1/43 |
| 匹配并集数量的MMD | 69.0625 | 0.864234258 | -0.000131211 | 2/0/46 |
| MMD先交替 | 50 | 0.864132054 | -0.000233415 | 5/3/40 |
| A-opt先交替 | 50 | 0.864132054 | -0.000233415 | 5/3/40 |
| MMD再A-opt | 50 | 0.864414475 | +0.000049006 | 6/6/36 |

并集大小逐任务为55至89，平均增加19.0625次评价。与逐任务数量完全匹配的MMD相比，
并集平均Brier仍低0.000124875，任务计数为4个更好、1个更差、43个相同。
因此，在这个预算下，并集的全部均值收益不能简单归结为评价数量增加；但差距小、覆盖任务少，且尚未计时。

固定50个评价的交替规则也有小幅平均收益。不过，其六个域均值仅2个更好、1个更差、3个相同，
不能将5个改善重复任务写成5个独立任务族上的确认。
Ridge下，固定50个评价的MMD先交替规则平均Brier差为-0.000002410，属于更小的绝对差距。

## 完整预算敏感性

下表为Logistic、新增种子、最终Brier差。前三列相对同预算MMD；最后一列相对逐任务等并集数量的MMD。

| s | MMD先交替 | A-opt先交替 | MMD再A-opt | 并集减等数量MMD |
| --- | ---: | ---: | ---: | ---: |
| 10 | +0.000717791 | +0.000717791 | +0.000497697 | +0.000055210 |
| 25 | -0.000342080 | -0.000187362 | -0.000767926 | -0.000155185 |
| 50 | -0.000233415 | -0.000233415 | +0.000049006 | -0.000124875 |
| 100 | +0.000028303 | +0.000028303 | +0.000183972 | +0.000028303 |
| 227 | 0 | 0 | 0 | 0 |

级联在25候选预算下出现改善信号，17个任务更好、7个更差、24个相同；
在10、50、100候选预算下则有更差的平均Brier。不能只选择25这一行报告成功。
交替规则同样不是所有预算占优；MMD先还是A-opt先的差异也如实保留，没有根据测试结果选择顺序。

在227预算下，Ridge与Logistic的所有规则最终Brier都与MMD相同，即使召回率有所变化。
原投影种子的单列对照也呈现这种饱和现象；其完整结果保存在CSV中，未混入新增种子均值。

每个指标各自按对应验证损失选择，并非对Brier选中的同一个模型重复计算三个指标。

## 对下一步的判断

- 值得保留的假设是：两种排序在部分小预算上具有互补性，而不是A-opt能够普遍修正MMD。
- 当前交替排序比“统一用A-opt重排MMD名单”更值得进入下一轮候选方案，但这是探索性筛选建议，不是确认结果。
- 下一轮应冻结规则和预算，在新的候选构造或独立数据上验证最终损失与失败比例，并独立测量双评分开销。
  仅重新划分同一批图像只能检查候选构造敏感性，不能替代独立数据确认。
- 原227预算几乎没有最终Brier改善空间，继续只看该预算的高召回不会验证新算法价值。
- 本轮不支持新增SOTA声明、风险保证或端到端加速声明，未将这些结果导入论文。
