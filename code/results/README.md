# Results directory

This directory is populated by running the reproducibility pipeline:

```bash
cd ..
python run_all.py
```

Each experiment writes a CSV or JSON file here. The deterministic E1a
cross-check is committed as `e1a_synth_grid.csv` and `e1a_summary.json`;
it records the exact generator, numerical-rank policy, and superadditivity
definition used for Table 1. Its 10,000-resample intervals are recorded in
`e_confidence_bootstrap.csv` and `e_confidence_summary.txt`. Larger real-data
outputs are regenerated by the pipeline and require the datasets described
in `../REPRODUCE.md`.

See `../REPRODUCE.md` for full instructions.
