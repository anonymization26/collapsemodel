# Target-Conditioned Data Selection 实验计划

> 状态：实验预注册草案。本文档只描述待执行实验，不把既有 Collapse-4S 结果自动视为新方法的证据。

## 1. 实验目标

实验围绕一个直接问题展开：在给定目标分布或目标任务信息后，能否选择更有利于目标风险的数据集或样本，而不仅仅是选择谱结构更“丰富”的数据？

完整证据链分为五层：

1. 验证冻结线性模型中的风险公式、边际增益公式和优化性质。
2. 在可控合成数据上识别方法成立与失效的条件。
3. 在真实冻结表示上验证目标条件选择是否优于目标无关选择。
4. 验证低秩摘要能否在降低通信与计算成本的同时保留选择质量。
5. 仅在前四层通过后，测试结论能否条件性扩展到微调、NTK 或梯度特征。

主评价量必须是目标风险或其可靠代理。有效秩、谱熵、子空间覆盖率和 Collapse 分数只作为解释变量、基线分数或压缩诊断量，不能替代目标风险。

## 2. 预注册假设与判定门槛

### H1：冻结贝叶斯线性模型的公式正确

- 后验目标风险解析式与蒙特卡洛估计的相对误差小于 `1e-3`。
- Sherman-Morrison 样本边际增益和 Woodbury 数据块边际增益与直接矩阵求逆结果的相对误差小于 `1e-10`（双精度、小规模问题）。
- A-opt 松弛的数值 Hessian 不出现超出数值容差的负特征值。
- D-opt 目标通过随机集合和穷举小实例的单调性、边际递减检查。

任一代数一致性检查失败，停止真实数据主实验并先修正实现或理论。

### H2：目标条件信息具有可测价值

在相同数据访问权限、候选集合、预算和搜索预算下，目标条件 A-opt 方法相对最强目标无关基线应满足：

- 跨预注册任务的目标风险平均相对改善大于 `2%`；
- 配对 bootstrap 的 `95%` 置信区间上界低于零；
- 至少 `70%` 的任务不劣于最强目标无关基线，容差为目标风险的 `0.5%`。

扩展确认性网格另设同权限 H2b：Target A-opt 必须相对能访问同一无标签目标二阶矩的
Target-Energy 和二阶特征 MMD 基线满足相同三项门槛。H2 与 H2b 分开报告；不能只用目标无关
基线通过 H2 就宣称 A-opt 结构优于简单目标匹配。

若只在个别数据集或编码器上成立，论文结论必须限定到对应设置。

### H3：数据集级预筛选可以减少昂贵评估

令 `Q = min(10, N_comb)`，其中 `N_comb` 是该设置下可行组合总数。在保留至少 `90%` 的真实
top-`Q` 候选组合召回率时，进入昂贵训练或精确评价的组合数减少至少 `50%`。同时，最终选中组合
相对穷举最优组合的归一化遗憾不超过 `5%`。

### H4：样本级选择优于等预算经典方法

在 `1%/5%/10%/20%` 样本预算下，目标条件样本选择应在冻结线性评估中：

- 相对 uniform、ridge leverage、k-center、facility location 和适用的监督式 coreset 方法报告完整对比；
- 在至少两个编码器、两个真实基准上达到最优或与最优方法统计等价；
- 给出准确率以外的目标 MSE、Brier score 或 NLL，避免只凭分类准确率下结论。

### H5：低秩摘要具有实际压缩价值

数学正确性要求所有确定性风险区间均覆盖 full-Gram 真值。实用性另设门槛：

- 在不超过 full-Gram `25%` 的传输字节数时，至少 `50%` 的选择比较可由区间直接判定；或
- 使用自适应增加秩及回退机制后，以不超过 full-Gram `50%` 的平均字节数得到与 full-Gram 相同的最终选择。

若只能保证区间覆盖而不能降低资源消耗，则低秩摘要只作为正确但不实用的附属结果。

### H6：失效条件可被主动诊断

随着条件偏移、标签置换或目标协方差估计误差增加，风险代理与真实风险的对应关系应出现可解释退化。实验必须保留这些负结果，不用事后筛选删除。

### H7：非线性扩展必须通过独立门槛

只有冻结表示实验通过 H2-H5，才执行真实微调。进入主论文结论需同时满足：

- 线性或 NTK 代理与微调后目标风险的 Spearman 相关系数中位数至少为 `0.6`；
- 所选数据在实际微调中优于等预算最强基线，且置信区间排除零；
- 报告线性化残差，证明改善不是偶然的候选排序吻合。

## 3. 信息权限与公平比较

所有方法按可访问的信息分组，跨权限的结果不能直接宣称方法优劣。

| 权限 | 可用信息 | 典型用途 |
| --- | --- | --- |
| U0 | 源数据无标签表示、无标签目标表示 | 默认匿名数据选择和预筛选 |
| U1 | U0 + 源标签或源训练损失 | 与监督式 coreset 方法比较 |
| U2 | U1 + 少量目标标签 | 直接目标风险估计和少样本目标适配 |

公平性约束：

- 所有方法使用相同的冻结编码器、特征归一化、候选池、预算和随机划分。
- 需要标签、梯度或目标验证集的方法必须标明权限，不能与 U0 方法混成一个排行榜。
- 搜索型方法使用相同的候选评估次数或分别报告搜索成本。
- full-Gram 与 rank-`L` 版本分开报告；不能让一个方法使用 full-Gram，而让对手只使用压缩摘要。
- 超参数只能在训练或验证任务上选择，目标测试集只在方案冻结后打开一次。

## 4. 数据与任务构造

### 4.1 合成数据

构造可精确控制的线性高斯环境：

- 维度 `d in {32, 128, 512}`；
- 候选数据块数 `M in {8, 16, 32}`；
- 选择预算 `K in {1, 3, 5}`；
- 目标协方差有效秩覆盖低、中、高三档；
- 源与目标主子空间夹角覆盖 `0` 到接近正交；
- 样本数、观测噪声和先验强度做正交变化；
- 条件机制从完全共享逐步过渡到标签置换和反向条件关系。

小规模设置穷举所有组合得到真实最优解；大规模设置同时报告凸松弛下界、贪心解和有限预算搜索结果。

### 4.2 真实冻结表示基准

优先选择标签空间兼容、具有明确域划分的数据集：

- DomainNet：多视觉域、大规模候选池；
- Office-Home：四域，适合完整组合枚举；
- PACS：四域，适合跨风格迁移；
- Camelyon17-WILDS：站点变化，检验真实分布偏移。

每个基准独立实验，不在标签空间不一致的数据集之间拼接训练。每次将一个域设为目标域，其余域
构成源候选池。为获得足够的候选数据块，在每个源域内按预先固定的样本哈希进行近似等大小的无标签
分片；分片过程不得使用类别标签、损失或模型预测。选择预算同时报告块数和实际样本数，避免少数
不等长尾块造成隐含数据量优势。

目标域拆为三部分：

- `target-selection`：U0 可见的无标签特征，仅用于估计目标协方差；
- `target-calibration`：仅 U2 实验可见的少量标签；
- `target-test`：只用于最终评价。

固定并保存样本 ID、域、划分和哈希分片清单。禁止根据实验结果重新划分候选池。

### 4.3 编码器

首轮使用两种结构差异明显的编码器进行门控实验：

- ImageNet 监督预训练 ResNet-50；
- 自监督 DINOv2 ViT-B/14。

H2 通过后扩展到：

- ImageNet 监督预训练 ViT-B/16；
- CLIP ViT-B/32 图像编码器。

每个模型固定权重版本、输入分辨率、预处理、抽取层和特征归一化方式。主分析使用最终池化表示，层级表示只作为后续敏感性分析。

## 5. 比较方法

### 5.1 U0：无标签源与无标签目标

- Random：重复随机选择，是方差基准而非单次运行。
- Size/Balance：按数据量或等量分配。
- Effective Rank：按单块有效秩或组合有效秩选择。
- Collapse-4S：仓库中统一后的唯一实现。
- Spectrum/Rank-`L`：已有谱摘要和低秩合并评分。
- DPP/Subspace Diversity：基于候选子空间或 Gram 相似性的多样性选择。
- k-center / k-medoids：表示空间覆盖。
- Facility Location：经典子模覆盖目标。
- MMD / target coverage：匹配源组合和目标特征分布。
- Target A-opt Full：使用 full-Gram 的目标条件风险代理，主方法上界版本。
- Target A-opt Sketch：使用 rank-`L` 摘要和误差证书。
- Bayesian D-opt：参数信息增益目标，作为具有子模结构但不使用目标协方差的理论基线。

### 5.2 U1：可访问源标签或梯度

- Class-balanced random。
- Ridge leverage / supervised leverage。
- CRAIG。
- GradMatch。
- 基于源验证损失或梯度相似度的选择。

若某算法的标准实现不支持冻结表示或多源块选择，必须记录最小适配方式，不以方法名称掩盖自定义实现。

### 5.3 U2：少量目标标签

- 少量目标验证集上的直接经验风险排序。
- 使用充分统计量 `(G_i, B_i)` 的精确 ridge 风险。
- 目标标签引导的 source weighting。
- 小规模穷举 oracle。

Oracle 只用于测量遗憾和上限，不计入可部署方法的胜负统计。

## 6. 实验矩阵

### E0：公式、优化性质与反例单元实验

目的：在任何经验结论前验证数学基座。

1. 随机生成正定先验、源 Gram 和目标协方差。
2. 对比解析 Bayes 风险与后验采样蒙特卡洛风险。
3. 对比单样本和数据块边际公式与直接重算结果。
4. 检查 A-opt 连续松弛的凸性。
5. 穷举 D-opt 的单调性与边际递减。
6. 自动搜索 A-opt 不满足子模性的最小反例，并固化为回归测试。
7. 构造相同无标签边缘分布、不同条件标签机制的不可辨识反例。
8. 验证所有 rank-`L` 风险上下界的覆盖关系。

输出：`e0_validation.json`、反例参数、数值容差报告和对应测试代码。

### E1：合成目标选择

目的：分离子空间覆盖、噪声、样本量和条件偏移的作用。

- 比较所有 U0 方法与穷举最优解。
- 独立扫描源-目标子空间夹角、谱衰减、目标样本量和标签机制偏移。
- 几何、目标采样、源采样和条件偏移方向使用独立 RNG 流；目标样本量扫描共享同一真实问题、
  同一源候选池和嵌套目标样本，预算扫描共享同一目标测试集。
- 报告目标风险、归一化遗憾、top-`Q` 召回、秩相关和失败率。
- 对每个参数配置至少运行 `20` 个随机种子；先在配置内跨 seed 聚合，再以参数配置为 bootstrap
  单位，不能把 seed×参数组合或单个样本当成彼此独立的重复。
- 绘制“目标协方差估计误差 -> 选择遗憾”和“条件偏移 -> 风险代理失真”曲线。

### E2：真实数据集级冻结 ridge 选择

目的：检验仅用无标签目标表示时，目标条件几何是否能改善真实下游风险。

流程：

1. 一次性抽取并冻结全部表示。
2. 从 `target-selection` 估计目标协方差。
3. 在固定预算 `K` 下选择源数据块。
4. 只在选中数据上拟合相同正则强度的 ridge 分类器。
5. 在 `target-test` 上报告 Brier score、NLL、MSE 代理和准确率。
6. 对小候选池穷举组合；对大候选池至少枚举到计算允许的最大 `K`，其余使用统一搜索预算。

主分析采用每个目标域内配对比较，再跨目标域和数据集做层级汇总。编码器不能作为独立样本简单扩充显著性。

### E3：少量目标标签与充分统计量

目的：测量从 U0 到 U2 增加目标监督后的边际价值。

- 目标标注预算：总计 `16/32/64/128` 个样本，并做类别覆盖敏感性分析。
- 比较目标协方差代理、充分统计量精确 ridge 风险和直接验证集经验风险。
- 使用嵌套划分选择正则参数，禁止同一目标标签同时调参和报告性能。
- 报告增加一个目标标签带来的平均遗憾下降及其置信区间。

### E4：样本级与层级 coreset

目的：从“选数据集”扩展到“选数据集中的数据”。

- 样本预算：源池总量的 `1%/5%/10%/20%`。
- 比较 uniform、class-balanced、ridge leverage、k-center、facility location、CRAIG、GradMatch、直接 Target A-opt 和 Target A-opt Sketch。
- 评估“先选数据块、再块内选样本”的层级方法，并与直接全池样本选择对比。
- 控制最终训练样本数、每类上限、优化器、正则和训练轮数。
- 除预测性能外，报告选择时间、峰值内存和摘要传输字节数。

### E5：低秩摘要、证书与通信成本

目的：验证低秩表示是可审计的计算后端，而不是独立正确性主张。

- 秩预算 `L in {4, 8, 16, 32, 64, 128}`，并加入基于区间重叠的自适应增秩。
- 比较 full-Gram、固定 rank-`L`、自适应 rank-`L` 和无证书启发式。
- 记录风险区间覆盖率、区间宽度、可直接判定的候选对比例、最终选择一致率、平均传输字节和运行时间。
- 将源 Gram 尾部误差、目标协方差误差和数值误差分别记录，禁止只给总误差。
- 若区间重叠无法判定，必须回退到更高秩或 full-Gram；不能强行打破平局。

### E6：多目标与鲁棒选择

目的：避免方法只对单个已知目标域有效。

- 平均风险：使用多个目标协方差的加权平均。
- 最坏目标风险：最小化候选目标集合中的最大风险。
- 留一目标域外推：不使用被留出目标域调参与设阈值。
- 编码器外推：在一个编码器上选择，在另一个编码器上验证候选排序稳定性。
- 报告平均目标风险、最坏目标风险和 Pareto 前沿。

### E7：NTK、梯度特征和真实微调

这是条件执行实验，不作为冻结表示结论的必需部分。

1. 构造最后一层、最后一个 block 和全模型近似 Jacobian 特征。
2. 测量有限步训练后的线性化残差。
3. 比较 Gram 风险代理、NTK 风险代理与实际微调结果的排序相关。
4. 对选中数据运行相同优化预算的真实微调。
5. 当线性化残差过大时，明确标记理论不适用，不把微调偶然收益归因于冻结线性理论。

### E8：端到端资源节省

仅在 E7 通过后执行：

- 固定候选和选择规则后，只训练预筛出的 shortlist。
- 与“训练全部候选后选最优”比较 NPU 时长、能耗代理、磁盘读写和最终风险。
- 将特征抽取、摘要构建、选择、训练和验证成本全部纳入，避免只报告训练阶段节省。

## 7. 指标定义

### 7.1 主要指标

- 目标预测风险：回归使用 MSE，分类使用 Brier score，并辅以 NLL。
- 归一化遗憾：

  `Regret(S) = (R(S) - R(S*)) / max(|R(S*)|, eps)`，

  其中 `S*` 是相同权限和预算下的穷举最优组合。
- top-`Q` 召回率：预筛 shortlist 覆盖真实 top-`Q` 组合的比例。
- 最坏目标风险：多目标设置中各目标风险最大值。

### 7.2 次要指标

- Accuracy、macro-F1、ECE。
- 候选排序的 Spearman 和 Kendall 相关。
- 选择时间、训练时间、峰值内存、传输字节。
- 证书覆盖率、区间宽度和回退率。

### 7.3 统计单位

- 主要推断单位是目标域或预注册任务，不是单个测试样本。
- 每个目标域内使用配对 bootstrap；跨域汇总使用层级 bootstrap 或混合效应模型。
- 随机方法至少 `20` 次重复，训练方法至少 `5` 个随机种子。
- 同时报告效应量、`95%` 置信区间和原始任务级结果，不只报告显著性。
- 多方法比较使用 Holm 校正；探索性分析与确认性分析分表展示。

## 8. 误差账本

每个结果都应对应以下误差来源，而不是把偏差统一归为“实验噪声”：

| 误差来源 | 测量方式 | 对应实验 |
| --- | --- | --- |
| 模型失配 | 解析风险与真实冻结 ridge 风险差异 | E1、E2 |
| 条件偏移 | 固定边缘协方差，改变标签机制 | E1 |
| 目标协方差采样误差 | 改变 `target-selection` 样本量 | E1、E2 |
| 低秩截断误差 | full-Gram 与 rank-`L` 差异及证书宽度 | E5 |
| 搜索误差 | 贪心或启发式与穷举最优差异 | E1、E2 |
| 少标签估计误差 | 改变目标标注预算 | E3 |
| 优化误差 | 闭式 ridge 与迭代训练差异 | E2、E7 |
| 线性化误差 | NTK 预测与真实参数更新差异 | E7 |

主论文每个性能表旁应注明该结果控制了哪些误差、仍暴露于哪些误差。

## 9. 数据泄漏与复现约束

- 所有样本划分写入版本化 manifest，并记录内容哈希。
- 候选分片在查看标签和结果前生成。
- `target-test` 不用于协方差估计、超参数选择、早停或方法筛选。
- 编码器权重、数据版本、预处理、随机种子和硬件环境写入运行元数据。
- 原始逐任务结果必须保留，汇总表由脚本自动生成。
- 失败运行不得静默删除；异常排除需在日志中给出预注册规则和原因。
- 旧版实验可作为探索证据，但新论文确认性结论必须由本计划下的固定流水线重新计算。

## 10. 计算计划与 NPU 使用

### 10.1 门控原则

1. E0 和 E1 主要使用 CPU，完成前不占用 NPU。
2. E2 先只运行 ResNet-50 和 DINOv2、Office-Home 和 PACS。
3. H2 初步通过后，再扩展到 DomainNet、Camelyon17 和其余编码器。
4. E7 和 E8 最昂贵，只有 H2-H5 通过后才能进入队列。

### 10.2 时间测量

不在缺少实测吞吐时给出虚假的固定总时长。每类任务先运行至少 `10` 个代表性 job，记录：

- 数据读取时间；
- 单 NPU 特征抽取样本/秒；
- Gram 或摘要构建时间；
- 单组合 ridge 拟合和评价时间；
- 峰值设备内存与主机内存；
- 多卡扩展效率。

随后按以下方式更新估计：

`T_extract = total_samples * num_encoders / measured_throughput`

`T_search = num_candidates * time_per_candidate / parallel_workers`

`T_total = T_extract + T_summary + T_search + T_train + T_eval`

报告乐观、中位和保守三档估计，并每完成一个阶段用实际用时校准剩余计划。

### 10.3 NPU 4-7 调度建议

- NPU 4-7 各自运行独立的“数据集 x 编码器”特征抽取任务，避免单任务跨卡通信。
- 摘要构建和 ridge 穷举优先在 CPU 上向量化执行，除非基准证明设备加速有明显收益。
- 每张卡保留独立日志和结果目录，任务完成后校验样本数及特征哈希。
- 同一确认性实验的不同随机种子均匀分配到设备，避免设备与实验条件混杂。

## 13. 停止规则与结论边界

- H1 失败：理论或实现错误，停止后续实验。
- H2 失败：保留为“目标条件二阶几何不足以稳定预测目标风险”的负结果，不继续包装成选择方法。
- H3 失败：不能宣称有效预筛选，只能讨论候选排序相关性。
- H4 失败：不能宣称方法适用于样本选择。
- H5 失败：不能宣称低秩摘要带来实际压缩收益。
- H7 失败：论文结论严格限定于冻结表示和线性读出，不外推到深度网络微调。
- 只有在多个数据集、编码器和目标域上通过相同预注册门槛，才使用“通用”或“稳健”措辞。

## 15. 最小可行执行顺序

第一轮只执行以下路径：

1. E0 全部验证。
2. E1 小规模和中规模合成实验。
3. E2 的 Office-Home、PACS、ResNet-50 和 DINOv2。
4. 若 H2 通过，执行 E4 的 `5%/10%` 样本预算。
5. 若 H4 通过，执行 E5 的 rank-`L` 与自适应证书。
6. 根据 H2-H5 决定扩展真实数据规模或停止。

这一路径先回答“目标条件几何是否真的比目标无关谱启发式更接近目标风险”，再投入大规模 NPU 资源。
