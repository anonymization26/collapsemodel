## 目录约定

- `iclr2027/`：唯一维护中的最新版，包含中英文源稿、PDF、摘要、图表、正式模板及构建/核验脚本。
- `archive/`：只读历史材料，见 [归档索引](archive/README.md)。旧 NeurIPS 稿已完整移入
  `archive/neurips2026/`；不再在本目录根部保留旧稿入口。

现论文依赖的实验数据仍保留在仓库 `results/` 中，未因归档而迁移或改写。
请勿将归档摘要、图表或历史主张与新稿混用。新实验的主结论以新稿及其明确列出的结果目录为准。
