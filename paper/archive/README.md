- 每个归档子目录的 `SHA256SUMS` 记录纳入版本管理的源文件、PDF 和图表，可在该目录执行
  `shasum -a 256 -c SHA256SUMS` 检查。
- 原有本地编译中间文件也随旧稿移动，没有删除；完整本地校验记录为 `SHA256SUMS.local`。
  这些缓存及本地清单继续被 Git 忽略，不是从仓库重新构建的必要输入。
- 需要重编旧稿时，在 `neurips2026/` 内使用其自带的 `neurips_2026.sty`、`references.bib` 和
  `figures/`。建议复制到临时目录后重编，保持归档字节不变。
- 最新版的正式 `iclr2027-style/`、当前生成图表与数据哈希清单全部保留。当前编译日志仍在
  最新稿目录并由 Git 忽略，供 `verify_draft.py` 检查实际依赖及版式。
- 仓库 `results/` 和 `code/` 未迁移：其中历史实验也可能是最新版的失败证据或图表来源，
