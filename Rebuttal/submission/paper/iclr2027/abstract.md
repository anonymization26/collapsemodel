# Abstract

Selecting among combinations of existing source pools requires a separate model fit and a target-validation score for every combination tried. A fixed feature ranking decides which combinations to try before any validation scores are available. When combinations share pools, early losses can help decide which untried combinations are worth fitting. We estimate additive pool effects from these losses and use the estimates to allocate the remaining fits. A full-rank set of queries identifies every candidate's validation loss under exact additivity and exact observations. We also relate Target A-opt to target prediction risk under a shared linear model and give an equal-cost example in which closer moment matching increases risk. On DomainNet, our policy selects a model with 25 logistic fits and nearly matches the mean test Brier score of exhaustive validation with 455 fits. With the initial fits held fixed, using feedback to choose the remaining fits lowers mean test Brier relative to continuing a fixed moment-matching ranking. Repartitioning the same Optdigits examples weakens the additive approximation and can favor fixed screening.
